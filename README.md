# Design Library

Browsable React + Tailwind showcase for the Habibi design system used across Unilever H3L, Nexus/Polaris, and future internal products.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This project is prepared for GitHub Pages through `.github/workflows/deploy.yml`.

After the project is pushed to a GitHub repo, enable GitHub Pages with source set to GitHub Actions.
